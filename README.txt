Great India Cartoon Video Builder

1. Open index.html in Chrome/Edge.
2. Upload a .txt script or paste a script.
3. Click Script से Cartoon Scenes बनाएं.
4. Click Preview to preview the scene animation.
5. Click Create Video.
6. Click Download Video to download the generated WebM video.

Important:
This offline version converts the script into timed animated cartoon scenes in the browser.
It does not call an external AI image/video generation API, so it does not yet generate photoreal/AI character images or AI lip-sync.
